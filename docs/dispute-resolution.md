# Dispute resolution

The canonical contract for structured social disputes lives at
[Disputes](disputes.md). This path is kept as a compatibility landing page and
does not duplicate the contract.

A dispute remains one owner's belief about attributed claims, testimony,
evidence references, rule references, mediation links, and proposed or declared
resolutions. It is never a shared case file, court record, judgment, verdict, or
objective truth, and no objective justice oracle or global dispute registry
exists.

Current catalog: 212 metric families; 43 commands; 73 observer semantic types; Alembic `0017`.
