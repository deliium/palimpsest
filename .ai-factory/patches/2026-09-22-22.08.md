# Wire persistence-backed API inspection/metric/replay services

**Date:** 2026-09-22 22:08
**Files:** src/api/persistence_services.py, src/api/app.py, src/api/dependencies.py, src/api/simulation_manager.py, src/api/schemas.py, src/api/streaming.py, src/api/routes/inspection.py, src/api/routes/replay.py, src/api/routes/streams.py, src/simulation/__init__.py, src/simulation/replay.py, tests/unit/test_api_composition.py, pyproject.toml
**Severity:** high

## Problem

Default `InspectionService` / `MetricReadService` / `ReplayApiService` were stubs that always returned `not_found` / unavailable. Routes appeared wired but default composition never attached persistence-backed implementations. Ruff flagged unsorted `__all__`; mypy flagged `RunControlRecord | None` reassignment, `Any` returns from repository factories, and `ApiError` exception-handler typing.

## Root Cause

Composition root (`app._lifespan`) attached `SimulationManager` when a session factory existed, but never constructed inspection/metric/replay facades from persistence factories. Dependencies fell back to empty stub classes. API boundaries correctly forbade `analysis`/`experiments`/`agents` imports, so adapters needed duck-typed opaque document mapping and string agent ids on `ReplayService.inspect_at_tick`.

## Solution

- Added `api.persistence_services` with `PersistenceInspectionService`, `PersistenceMetricReadService`, and `PersistenceReplayApiService` mapping loader/replay DTOs to public schemas without importing analysis/experiments.
- Attached those services in `_lifespan` after DB factory success when `app.state.*` overrides are absent (same pattern as SimulationManager).
- Extended `ReplayService.inspect_at_tick` to accept `str` agent ids so API need not import `agents`.
- Fixed mypy issues via renamed assignment, `cast(...)` on repository factories, and Exception-typed handler wrapper.
- Sorted `__all__`, configured ruff `extend-immutable-calls` for FastAPI Depends/Query, and added composition tests proving real service classes attach and overrides are preserved.

## Prevention

- When adding injectable API facades, always wire persistence-backed defaults in lifespan and keep stub base classes for tests only.
- Cover composition with a lifespan test that asserts concrete service types on `app.state`.
- Prefer duck-typed persistence ports in `api` over importing `experiments`/`analysis` record types.
- For FastAPI + ruff B008, configure `flake8-bugbear.extend-immutable-calls` once instead of scattering noqa.
