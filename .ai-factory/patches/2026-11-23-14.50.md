# V4-36 verify gaps: disease snapshot, pins, ruff, observer budget

**Date:** 2026-11-23 14:50
**Files:** src/simulation/runner.py, src/simulation/persistence.py, src/simulation/ecological_resources_config.py, src/simulation/engine.py, tests/unit/test_ecological_resources_observer.py, tests/unit/*ownership* and version pin suites, docs/architecture.md, docs/v4-architecture.md
**Severity:** high

## Problem

`$aif-verify` on `v4-36-ecological-resources` reported a failing gate even though
plan tasks were checked:

- Disease/medical runner bootstrap failed with
  `codec v22 requires DiseaseCheckpointSection disease_mechanics`.
- Full default pytest had 36 failures: stale live ownership/version pins still
  treating `ecological_feedback` as unowned, plus medical/disease regressions.
- `ruff check` failed on ecology config, unsorted `WorldEngine.__slots__`, and
  persistence line length.
- Observer hidden-batch test advanced past ecology rows but never asserted
  `observer_read_budget_exhausted`.

## Root Cause

1. **Asymmetric snapshot assembly.** `SimulationService` already built the
   disease checkpoint section for codec `v22`/`v23`, but runner
   `_engine_snapshot` only gained the ecology `v23` block. Disease-active
   bootstrap therefore selected `v22` without `disease_mechanics`.
2. **Latent artifacts allowlist gap.** Feature-channel codec allowlists for
   artifacts/lifecycle/etc. included travel `v25` but omitted disease `v22`,
   ecology `v23`, and measurement `v26`. Restoring disease assembly exposed
   medical scenarios that carry seed artifacts.
3. **Pin tests treated as frozen docs.** Live guards still asserted
   `ecological_feedback` unowned and `runner-config-v60` absent after ownership
   landed.
4. **Observer budget path untested.** Exclusive-scan cursor advancement was
   covered without exhausting `max(64, (limit+1)*16)`.

## Solution

- Ported the service disease checkpoint assembly into
  `runner._engine_snapshot` before the ecology block, with metadata-only
  `[FIX]` DEBUG logging of codec and row count.
- Extended feature-channel allowlists to accept `v22`/`v23`/`v26` without
  widening travel/infrastructure-required codec sets that pair schemas
  differently.
- Updated live ownership/version pin tests to 11 owned / only `disasters`
  unowned, accepted event schema 25, and next runner guard `v61`.
- Fixed ruff issues (collections.abc Mapping, redundant int cast, unused loop
  index, slots order, E501 wraps).
- Extended the ecology observer test with a 64-hidden-row exclusive-scan that
  asserts `observer_read_budget_exhausted`.

## Prevention

- When adding a new checkpoint codec, update **both** `service` and
  `runner._engine_snapshot` assembly paths in the same change, and include a
  disease/measurement/artifacts composition fixture if those channels can
  coexist.
- Treat live pin tests as compile-time contracts for owned flags and accepted
  versions; re-point “next unclaimed” guards instead of leaving prior
  reservations in the unowned set.
- For observer hidden-event pagination, assert both visible-page advancement
  and explicit budget exhaustion on the exclusive-scan path.
- Do not bulk-expand travel/infra schema-pairing sets when adding sibling
  codecs; only extend feature allowlists that mean “this codec may carry
  inherited channel bytes.”
