# Complete emotion.v1 driver coverage after verify gap

**Date:** 2026-09-24 20:35
**Files:** tests/unit/test_emotional_state_engine.py, src/agents/cognition/emotion.py, src/agents/cognition/communication.py
**Severity:** medium

## Problem

`/aif-verify` failed Task 12 as PARTIAL: engine smoke tests covered threat/goal/decay/passthrough but not every `EmotionDriverCode` (observation, memory_salience, social_interaction, relationship, physical_condition), gain/ceiling clamps, or disabled-kind rejection. Ruff also flagged `emotion.py` I001 and a long line in `communication.py`.

## Root Cause

Task 12 was marked complete after Task 5 smoke coverage. Verify correctly treated “each driver code + clamp + disabled kinds” as a separate deliverable from the engine implementation smoke suite.

## Solution

Extended `test_emotional_state_engine.py` with focused driver tests, a parametrized directional table for all active drivers, gain-cap and ceiling clamp cases, and disabled-kind WARN rejection. Fixed import sort in `emotion.py` and wrapped the long `WRITE_MEMORY` guard in `communication.py`.

## Prevention

When a plan task says “table-driven / each driver code,” require an explicit test matrix that enumerates every closed enum member before marking the task done. Do not equate engine smoke tests with Task 12 coverage. Keep verify’s PARTIAL→fail gate for incomplete matrices.
