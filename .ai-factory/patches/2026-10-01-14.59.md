# Public production exports failed Ruff RUF022

**Date:** 2026-10-01 14:59
**Files:** src/world/production.py, tests/unit/test_production_catalog.py
**Severity:** low

## Problem

`uv run ruff check src/world/production.py` failed with `RUF022`: `__all__` was not sorted. `ProductionInput` sat after `ProductionJob`.

## Root Cause

The export list was written by category and then tweaked by hand. Ruff's `__all__` check uses isort order, which groups constants, classes, and functions, then sorts inside each group. `ProductionInput` and `ProductionJob` are both classes, so `Input` must precede `Job`. A single `sorted()` call is not the same order, because it places `HeldItemKindInput` before `INITIAL_SHELTER_INTEGRITY`.

## Solution

Moved `ProductionInput` ahead of `ProductionJob`. Added `test_public_export_list_stays_sorted`, which sorts with the same three ranks Ruff uses: uppercase constants, Capitalized names, then remaining names.

## Prevention

After editing a public `__all__`, run `ruff check` on that module. A regression test should use the isort grouping, not Python's plain `sorted()`.
