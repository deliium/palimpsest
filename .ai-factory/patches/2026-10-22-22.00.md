# Generational runner verification gaps: exports, truthfulness, and artifact integrity

**Date:** 2026-10-22 22:00
**Files:** src/simulation/__init__.py, src/simulation/runner.py, src/simulation/run_control.py, src/simulation/runner_models.py, src/simulation/generational_seeds.py, src/experiments/generational_archive.py, src/experiments/generational_artifacts.py, src/experiments/generational_adoption.py, src/experiments/generational_execution.py, src/experiments/generational_sampling.py, src/experiments/catalog.py, src/experiments/__init__.py, src/experiments/matrix_runner.py, src/research_runner/cli.py, src/research_runner/generational_composition.py, tests/integration/test_generational_scale.py
**Severity:** high

## Problem

Post-implementation verification of v3-35 found blocking gaps: generational contracts were
not exported from `simulation`, seed metadata mislabeled sampled channels as deterministic
hashes, custom provider factories bypassed replay-usage evidence, replay archives could not be
built, a historical-artifact failure still produced `completion.json` (which matrix adoption
accepted), JSON duplicate keys and symlink escapes were not rejected, recovery carry omitted
cached decisions and pending-boundary enforcement, BL was absent from the catalog, the matrix
first skip path was state-only, and the 100000-tick scale test read completion without writing it.

## Root Cause

- Contract and composition work was implemented at the implementation point but not at the
  public facade or the production composition root.
- Failure handling was added to the runner evidence path but the archive writer still assumed
  every returned result was completable.
- Verification tests exercised helpers rather than the real manager/composition path, so stale
  skip gates and missing completion writes were not observed.
- Seed manifests were written from assumptions about channel behavior instead of the actual
  stream/namespace code.

## Solution

- Exported all v55/generational contracts, control state, ports, and stop classifier.
- Recorded environment as `sampled` under `system-effect`; mapped live/record/cache to sampled
  and replay/fake to deterministic hash; threaded recording identity into manifests.
- Rejected untracked custom provider factories in archival composition.
- Wrote `failure.json` (truthful boundary/stage/committed flags) instead of completion for
  failure stop reasons; guarded `write_completion`; adoption now rejects failure archives and
  validates recipe, seed, scenario, and cognition identities.
- Added duplicate-key rejection and symlink-escape checks to artifact stores.
- Added cached criterion decisions (per boundary), pending-boundary stage enforcement, recovery
  revision verification, entrant synchronization, and a pending-finalization guard in `finish_run`.
- Wired community sampling hooks and a live criterion factory through execution context.
- Registered BL in the catalog/off-gate set; matrix now requires a generational context and
  validates archives on both skip paths; CLI matrix wires durable/recording composition.
- Fixed the scale test to call `session.write_completion(result)` before reading it.
- Recorded `cell_id` in matrix assignment metadata, documented the 129-family pin,
  and added regressions for missing generational context and empty-population revival.
- Added `PostgresCommunitySampleProvider` and wired it into durable CLI composition so
  history samples and the `community_count_at_least@1` criterion use real snapshot evidence.

## Prevention

- Put new public contracts in the package facade in the same change as the implementation.
- Derive provenance metadata from the actual stream call, not a nearby assumption.
- Test the production entry point, not only the helper that it calls.
- Treat "failure result" and "completed archive" as mutually exclusive states in every writer
  and adopter.
- Keep strict JSON decoding duplicate-aware and verify path containment before any write.
- Run the release gate itself (and read its output) instead of inferring it from a smaller twin.
