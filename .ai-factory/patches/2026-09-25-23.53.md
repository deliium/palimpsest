# Sort identity intention test imports

**Date:** 2026-09-25 23:53
**Files:** tests/unit/test_identity_intention_influence.py
**Severity:** low

## Problem

`ruff check` on the identity-plan diff failed with `I001` in
`tests/unit/test_identity_intention_influence.py`. `GoalOutcomeKind` was
listed after `GoalStatus` inside the `agents.models` import.

## Root Cause

The intention-influence test was added and committed without a final
`ruff check` on that file. The isort check only failed later, during
`/aif-verify`, because the plan-diff lint stopped being run at the last
commit.

## Solution

Moved `GoalOutcomeKind` ahead of `GoalStatus` so the import block matches
isort. No runtime behavior changed. Re-ran `ruff check` on the identity-plan
Python files and `pytest` on this module (5 passed).

## Prevention

Run `ruff check` on every new or modified test module before the commit that
adds it, including files that only rearrange imports.
