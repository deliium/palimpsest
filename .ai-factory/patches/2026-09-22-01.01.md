# Verify blockers for social communication transmission

**Date:** 2026-09-22 01:01
**Files:** src/persistence/transmission_mapping.py, src/agents/cognition/communication.py, src/world/communications.py, src/simulation/subjective_serialization.py, tests/unit/test_multi_hop_communication_memory.py, tests/unit/test_v1_memory_property.py, tests/unit/test_subjective_state_serialization.py, tests/integration/test_social_transmission_analysis_persistence.py, tests/architecture/test_analysis_isolation.py
**Severity:** high

## Problem

`/aif-verify` failed after social-communication implementation:

1. Architecture allowlist: `persistence.transmission_mapping` imported `world.identifiers.EntityId`.
2. `test_competence_status_versus_risk_diverges` expected `Talk` but planner emitted `Tell` whenever owned beliefs existed.
3. Task 7–9 gaps: missing subjective codecs for testimony/transmission meta, missing PG analysis persistence test, thin multi-hop/Hypothesis/architecture coverage, lint/format debt.

## Root Cause

1. Persistence used a direct `world` import instead of the allowed `memory.models.EntityId` re-export used by sibling adapters.
2. `DeterministicSocialMessagePolicy` treated “any high-confidence belief present” as share-intent and always upgraded bare `COMMUNICATE` to belief-grounded `Tell`, conflicting with Task 5’s “selected” belief wording and risk-scenario Talk fallback.
3. Plan file lists for Phase 3 were only partially implemented (ORM path done; codec/tests/scenario breadth incomplete).

## Solution

- Import `EntityId` from `memory.models` in `transmission_mapping.py`.
- Gate belief→`Tell` on non-empty `selected_belief_ids`; log `belief_testify_requires_selection` / `selected_belief_testify`; keep ask/retell/recon/talk paths for bare `COMMUNICATE`.
- Add subjective codecs for `AppliedTestimonyFactors` and `CommunicatedTransmissionMeta`.
- Add PG analysis persistence integration tests, expand multi-hop talk/ask/isolation cases, Hypothesis hop/attenuation schedules, and architecture port isolation for `SocialTransmissionAnalysisService`.
- Ruff format/lint on plan-touched files.

## Prevention

- Persistence must only consume world identity types via `memory.models` (or other allowed facades); architecture tests already catch this — run them before commit.
- Social message policies must not equate “beliefs exist” with testify intent; require explicit selection for belief-grounded `Tell`.
- When a plan lists a new integration test file, create it in the same commit as the loader path it covers.
