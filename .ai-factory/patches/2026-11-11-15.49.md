**Severity:** high

## Problem

Post-implementation verification failed: `uv run mypy src tests` reported 227
strict errors in 26 V4-20 files; the Research UI vitest lane could not transform
`marketInstitutions.ts` because `CAPABILITY` was declared twice; the required
integration and boundaries suites were absent; the docs page used a different
filename and lacked mandated headings; and a required experiment test was
unconditionally skipped. Publication also mapped `analysis.markets` into
expectation records, a latent runtime error not exercised by tests.

## Root Cause

The market modules were written with runtime-only patterns that strict typing
rejects: helpers returned `tuple[object, ...]` or `tuple[object, ...]`-like
values, no-op `row = row  # type: ...` comments were used instead of real casts,
and pagination/API helpers accessed dataclass attributes through `object`.
Publication reused the wrong analysis family in `_expectation`. The UI test was
copied from a sibling panel without matching the repository's `test/mount`
helper, and the API module declared `CAPABILITY` twice. Verification-only
artifacts (integration test, boundaries test, docs parity, receipt) were marked
complete without being created.

## Solution

- Added generic `_rows[T]`/`_cap[T]` helpers with explicit `cast`, removed no-op
  redefinitions, and typed pagination/API row payloads as `Any` where Pydantic or
  dataclass validation owns the runtime contract.
- Fixed `_expectation` to iterate `analysis.expectations` and typed `_latest`
  helpers per row family.
- Guarded the optional venue location before minting a belief id.
- Removed the duplicate UI constant, matched the mount helper, and removed
  commercial vocabulary from rendered panel text.
- Added the DB-free integration suite, the boundaries suite, the strengthened
  docs parity/negative-claim checks, Hypothesis cap properties, the unrelated
  event digest property, and the real missing-regions failure test.
- Rewrote and renamed the docs page to `docs/market-like-institutions.md` with
  the required headings and `$aif-roadmap` note.
- Added the plan verification receipt and preserved metadata-only logging.

## Prevention

- Run `uv run mypy src tests` and `uv run ruff check src tests` before marking a
  task complete; do not treat `object`-typed helpers as harmless.
- Match sibling client tests through the shared `test/mount` helper and run both
  vitest and svelte-check.
- Create every explicitly named test/artifact; a checked task without its
  artifact is not complete.
- Exercise composed publication paths with non-empty owner rows so wrong-family
  bugs fail in tests.
- Keep docs parity checks sentence-scoped and headered, not token-only.
