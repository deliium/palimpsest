# Patch: Cognitive budget verify gaps

**Date:** 2026-10-03  
**Tags:** cognition, budgets, tests, ruff, docs, experiment-ad

## Root Cause

`/aif-implement` marked Tasks 5/8/9 complete while proofs were thin: ledger/unit smoke tests covered contracts, but graceful-degradation, trajectory isolation, runtime audit harvest, and Experiment AD low-vs-high branch charging under a shared seed were incomplete. Ruff also failed on changed exports/`__all__`/line length after the schema widen.

## Solution

- Added Task 5 proofs for branch/depth clamp via `_effective_prospective_policy`, memory truncate=1, ToM=0, reflection interval floor, and shared charge-sequence low &lt; high.
- Added Task 6 runtime `_commit_cognitive_budget_audit` export proof.
- Added Task 8 DISABLED + tracing-on/off `exact_trajectory_hash` equality on catalog A.
- Added Task 9 short AD arm runs asserting audits export and `low_branches < high_branches`.
- Fixed ruff on changed modules; documented `runner-config-v22` in `docs/simulation-runner.md`.

## Prevention

Before marking verify/test tasks complete, require (1) prepare-path or runtime harvest proofs for each locked degradation dimension, (2) trajectory-hash isolation when modes claim objective neutrality, and (3) `ruff check` on the full changed-file set including `__init__.py` exports.
