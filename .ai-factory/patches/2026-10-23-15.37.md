# Cultural evolution metrics verification gaps: coverage, mutation, and embedded JSON

**Date:** 2026-10-23 15:37
**Files:** src/analysis/cultural_evolution_evidence.py, src/analysis/cultural_narrative_survival.py, src/analysis/cultural_technology_continuity.py, src/analysis/cultural_evolution_transmission.py, src/analysis/cultural_population_structure.py, src/analysis/cultural_metric_comparison.py, src/analysis/cultural_evolution_metrics.py, src/analysis/cultural_trait_dynamics.py, src/analysis/cultural_vocabulary_differentiation.py, src/experiments/cultural_evidence.py, src/experiments/matrix_runner.py, src/experiments/coordinator.py, src/experiments/generational_execution.py, tests/unit/test_cultural_*.py, docs/cultural-evolution-metrics.md
**Severity:** high

## Problem

Post-implementation verification found blocking scientific and integrity gaps in
V3-37 cultural evolution metrics:

- Missing or disabled narrative/technology channel coverage was treated as an
  empty inventory, producing `PRESENT` zero retention/loss instead of unknown.
- Narrative `unresolved_baseline_count` was hardcoded to zero.
- Real practical-knowledge mutation edges could not resolve a donor because the
  normalizer matched donors by the receiver's target digest, then assigned that
  same digest to both source and target. Real mutations became `unknown_source`
  and `exact_fidelity` was trivially perfect for every resolved edge.
- Embedded `rows_json` was decoded with plain `json.loads`, without duplicate-key
  rejection or the required 16 MiB/depth bounds, and row-level `PARTIAL` values
  entered repeated-seed inference.
- Convergence did not publish excluded both-empty pair counts or membership
  churn, vocabulary candidate/retired bindings were not counted, production
  capture omitted objective kinship edges, and empty populations used
  `population_unavailable` instead of `population_empty`.

## Root Cause

Coverage was validated in the evidence contracts but several metric consumers
only looked at entries. An empty entry tuple therefore meant both "known empty"
and "not observed". The transmission normalizer also conflated donor resolution
with content equality: matching by target digest guaranteed equal digests after
resolution, so mutation could never be observed. Artifact hardening was applied
to the outer envelopes but not to the JSON string nested inside a metric
document. Production composition stopped at the recorder and never copied the
runner's objective kinship graph into normalized evidence.

## Solution

- Added `dimension_population` and used it in narrative/technology to censor
  incomplete or disabled channels and to emit `population_empty` /
  `channel_disabled` / `partial_baseline` / `partial_endpoint` explicitly.
- Computed unresolved baseline ancestry from owner-qualified missing parent refs
  and censored exact rates when unresolved.
- Resolved practical-knowledge donors by explicit source owner plus content key,
  using the donor entry's own digest as `source_digest`. Differing target digests
  now produce a resolved mutation edge instead of `unknown_source`.
- Added duplicate-aware, size/depth-bounded `rows_json` decoding and restricted
  inference to row-level `PRESENT` measurements.
- Published convergence exclusion/cohort/entrant/exit counts, counted candidate
  and retired terminology bindings, wired kinship parent→child edges through all
  production capture paths, and renamed empty-population reasons.

## Prevention

- For every metric that reads an optional channel, verify channel coverage before
  interpreting an empty entry set; add a missing-channel regression test next to
  the known-empty test.
- Never resolve a donor by the receiver's digest and then compare those same
  digests as fidelity evidence. Resolve donor identity independently, then hash
  each side.
- When hardening an artifact decoder, include nested JSON strings stored in metric
  values, not only top-level envelopes.
- Exercise the production composition path (runner → recorder → arm fields), not
  only the pure normalizer, for optional evidence such as kinship edges.
