# Persistence allowlist exceeded the ruff line length

**Date:** 2026-09-27 20:58
**Files:** tests/architecture/boundary_checker.py, tests/architecture/test_observer_isolation.py
**Severity:** low

## Problem

`ruff check` on the observer diff failed with `E501` at `tests/architecture/boundary_checker.py:70`. The persistence import set was one physical line longer than 88 characters. The observer entries added nearby were already wrapped.

## Root Cause

The persistence allowlist grew by appending package names to a single-line `frozenset` literal while neighboring layers (`simulation`, `experiments`) already used a wrapped literal. Ruff reports the whole file, so a pre-existing long line blocks a clean check of an otherwise valid diff.

## Solution

Wrapped the persistence set to match the neighboring literals, keeping the same five package names. Added `test_persistence_allowlist_includes_subjective_packages_only` so a later edit cannot drop `experiments` or admit `observer` while the line is being reformatted.

## Prevention

When an allowlist gains a member, wrap the literal if the line would pass 88 characters. After touching `boundary_checker.py`, run `ruff check` on that file, not only on newly added modules. Assert the exact persistence set in the observer isolation test so a wrap cannot silently change membership.
