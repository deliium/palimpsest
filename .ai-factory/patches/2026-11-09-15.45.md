# V4-16 static gates and append-only pin sweep were incomplete

**Date:** 2026-11-09 15:45
**Files:** `pyproject.toml`, `tests/architecture/boundary_checker.py`, `src/simulation/engine.py`, `src/simulation/infrastructure_codec.py`, `src/simulation/infrastructure_paging.py`, `src/world/events.py`, `src/world/infrastructure.py`, `src/world/_infrastructure.py`, `src/simulation/serialization.py`, `src/research_runner/infrastructure_composition.py`, `src/analysis/inter_society_relations_contract.py`, docs and test suites
**Severity:** high

## Problem

V4-16 shipped with a red full verification surface:

- `ruff check src tests` reported 44 errors in V4-16-touched files.
- `mypy src tests` reported 242 errors, at least 49 in new V4-16 code.
- `lint-imports` reported the `private world authority modules are simulation-only`
  contract broken because `world._infrastructure` was not in the allowlist.
- The full unit + architecture suite had 50 failures, 45 of which were new
  V4-16 regressions (stale metric catalog offsets, stale “infrastructure is
  unowned” tests, stale replay-v23 rejection tests, stale observation-freeze
  tests, stale docs pins, and observer semantic-table alias assumptions).

The focused 191-test selection used during implementation masked the broader
regressions.

## Root Cause

The append-only catalog and pin sweep was applied only to the handful of tests
named in the plan. Historical tests that index metric families by negative
offsets, assert owned-flag counts, or freeze observation/semantic tables were
not rerun outside the focused selection. Separately, the import-boundary
allowlists were not updated for the new private `world._infrastructure` module,
and the new code was not passed through the documented ruff/mypy commands before
certification.

## Solution

- Added `world._infrastructure` to both import-linter and AST boundary
  allowlists; kept `simulation.engine` allowed to import private world authority.
- Ran the documented static gates and fixed the new errors:
  - wrapped long lines, removed unused imports, sorted imports/`__all__`;
  - typed codec/paging/event/serialization payloads instead of using `object`;
  - narrowed event-detail unions in the engine;
  - updated `research_runner` argument handling.
- Replaced historical negative metric slices with absolute catalog indices so
  future appends cannot shift them.
- Updated owned-flag sets/counts, replay acceptance (v23 accepted, v24 rejected),
  observation freeze fields, observer alias closure, collective-project catalog
  expectations, and current docs pins (catalog 188).
- Fixed the stale Godot isolation docstring trigger and pre-existing ISR test
  typing so the repository-wide static gate is green.

## Prevention

- Run the full `uv run pytest tests/unit tests/architecture` suite before
  recording a Task 27 certification, not only a focused selection.
- Run `uv run ruff check src tests`, `uv run mypy src tests`, and
  `uv run lint-imports` exactly as documented in `docs/development.md`.
- When appending metric families, prefer absolute catalog indices in historical
  tests; negative slices are fragile under append-only growth.
- When adding a private world module, update both `pyproject.toml` and
  `tests/architecture/boundary_checker.py` allowlists in the same change.
- For alias-only observer semantics, assert set equality against
  `SEMANTIC_EVENT_TYPES` rather than tuple equality with the alias map.
