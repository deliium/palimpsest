## Root Cause
Task 12 auto-selected the first narrative variant and painted map hops, but never populated a selector UI or focused opaque `source_event_id` / `last_communication_id` lines in the event log. Separately, three ruff import/line-length findings remained on the strategy-audit Python paths.

## Solution
- Added `NarrativeSelector` (SUBJECTIVE OptionButton) wired through `ui_layer` / `main`.
- Event log stores `event_id`, supports `focus_event_ids` / `clear_event_focus`, and marks matching lines.
- Narrative overlay exposes `selected_opaque_event_ids()` for log focus only (no content tokens).
- Fixed ruff I001/E501 on `adapt.py`, `strategy_audit.py`, and the audit unit test.

## Prevention
When a plan lists `event_log.gd` focus hooks and a selector, verify UI wiring end-to-end (payload → selector → overlay select → log focus) before marking the task complete. Run `ruff check` on touched Python before verify.
