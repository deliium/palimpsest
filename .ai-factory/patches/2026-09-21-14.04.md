# Fix verify gates: mypy, LLM caplog, ruff format

**Date:** 2026-09-21 14:04
**Files:** tests/fakes/cognition.py, tests/architecture/test_cognitive_loop_isolation.py, tests/unit/test_agent_runtime.py, tests/unit/test_llm_trust_boundary.py, tests/unit/test_llm_options.py, tests/unit/test_llm_correlation.py, tests/unit/test_openai_compatible_provider.py, plus ruff-format on LLM/infra files
**Severity:** medium

## Problem

`/aif-verify` failed after the V1 cognition/runtime plan: strict mypy reported errors in new cognition tests; default pytest failed two LLM log assertions; repo-wide `ruff format --check` failed on nine LLM/infra files.

## Root Cause

1. Mypy does not narrow unions after `type(x) is T` the same way as `isinstance`; `BoundaryViolation` exposes `file` not `path`; successive `status is Enum` asserts after mutation keep a stale Literal narrow; unused `# type: ignore` comments drifted.
2. Caplog at DEBUG for `llm.openai_compatible` still records sibling `httpx` INFO lines (URLs without `llm_request_id`), so assertions over all `caplog.records` mixed transport noise with provider metadata logs.
3. Prior LLM commits left formatting that no longer matched the active ruff line-length rules.

## Solution

- Narrow scripted fake outcomes with `isinstance` + assert success type.
- Use `BoundaryViolation.file`; compare runtime status via `.value` to avoid comparison-overlap.
- Filter LLM log assertions to `record.name == "llm.openai_compatible"`; patch `httpx.AsyncClient` on the `httpx` module; compare StrEnum `.value` strings.
- Run `ruff format` on the nine unformatted files.

## Prevention

- When asserting provider logs, always filter by the owned logger name; never treat caplog as exclusive to one logger.
- Prefer `isinstance` for mypy-visible narrowing in harness code; avoid `type(x) is T` when a union attribute is read after the branch.
- After enum-mutating methods, avoid chained `is` identity asserts on the same property; use `.value` or a fresh local without prior Literal narrowing.
- Run `ruff format --check`, `mypy`, and default `pytest` before marking plan Task 7 complete.
