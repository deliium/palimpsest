# Keep causal hypothesis store off the Pydantic import chain

**Date:** 2026-09-26 18:06
**Files:** src/agents/cognition/world_model.py, src/agents/cognition/world_model_selection.py, src/agents/cognition/loop.py, pyproject.toml, tests/unit/test_causal_world_model_experiment.py
**Severity:** high

## Problem

`lint-imports` broke the contract "Domain, simulation, and analysis must not import Pydantic". The shortest chain was `agents.cognition.world_model -> llm.models -> pydantic`. Simulation and analysis import the hypothesis store, so that edge leaked Pydantic into those packages.

## Root Cause

Provider selection was placed in the same module as the hypothesis store, and it imported `llm.models` directly. `simulation.perception`, `simulation.run_control`, and `simulation.runner` load that store. Import-linter reports only the shortest chain, so the existing `agents.cognition.reflection -> llm` facade edge stayed hidden until the shorter `llm.models` edge was the one on the report.

## Solution

Moved id selection into `agents.cognition.world_model_selection`, which imports the `llm` facade the way consolidation and reconstruction do. The store no longer imports `llm`. The loop loads the selector only when `allow_provider` is true. The facade edges for reflection and the new selector are on the same `ignore_imports` allowlist as the other cognition modules that are allowed to use the LLM facade.

## Prevention

Do not import `llm.models` from a cognition module that simulation or analysis loads. Provider calls belong in a module that imports the `llm` facade, and that facade edge must be listed in the Pydantic contract's `ignore_imports`. After moving an import, rerun `lint-imports` so a longer chain is not left in place of the one just removed.
