# Clear Ruff lint on cognition-trace modules

**Date:** 2026-09-23 16:29
**Files:** src/agents/cognition/trace.py, src/simulation/cognition_trace.py, src/simulation/cognition_trace_serialization.py, src/simulation/compatibility.py, src/simulation/runner.py, tests/unit/test_cognition_trace_projection.py, tests/unit/test_cognition_trace_regression.py
**Severity:** low

## Problem

`/aif-verify` reported 15 non-blocking Ruff findings on the cognition-trace
implementation: E501 line length (>88), I001 unsorted imports, RUF022 unsorted
`__all__`, and RUF005 tuple concatenation.

## Root Cause

Long single-line constructor/require calls and assert expressions were added
during feature implementation without a final `ruff check` pass on the changed
files. Import/`__all__` drift came from incremental edits that did not re-run
auto-fix.

## Solution

- Wrapped long `require_*` / type-check / assert / dict-comp lines to ≤88 cols
- Applied `ruff check --fix` for I001 and RUF022
- Replaced `tuple(kept) + (stage,)` with `(*kept, stage)` (RUF005)
- Re-ran related unit tests (31 passed)

## Prevention

- Run `uv run ruff check` on changed paths before each commit checkpoint
- Prefer wrapping long require/constructor calls early rather than single-line
- Include lint in `/aif-verify` remediation before marking style-clean
